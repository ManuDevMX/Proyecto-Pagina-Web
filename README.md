# 🌐 ManuDevMX - Sitio Web Profesional de Servicios

Sitio web landing page moderno, rápido y 100% responsivo desarrollado para la marca **ManuDevMX**, enfocado en la presentación de servicios de desarrollo web a la medida y captación de clientes.

🌐 **Demo en vivo:** [https://manudevmx.github.io/Proyecto-Pagina-Web/](https://manudevmx.github.io/Proyecto-Pagina-Web/)

---

## 🚀 Características Principales

- **📱 Diseño 100% Responsivo:** Adaptación fluida para celulares, tablets y computadoras mediante CSS Media Queries.
- **⚡ Efecto Typing Dinámico:** Animación en JavaScript puro que simula escritura en tiempo real para el subtítulo del encabezado.
- **💬 Cotización Directa por WhatsApp:** Enlace integrado con la API de WhatsApp para iniciar conversaciones de presupuesto pre-redactadas.
- **🎨 UI/UX Moderna:** Esquema de colores oscuro (*Dark Mode*) enfocado en tecnología y desarrollo.

---

## 🛠️ Tecnologías Utilizadas

- **HTML5:** Estructuración semántica del sitio web.
- **CSS3:** Maquetación moderna utilizando Flexbox, variables CSS y diseño adaptativo.
- **JavaScript (ES6+):** Manipulación del DOM para animaciones dinámicas e interactividad.
- **GitHub Pages:** Despliegue y hosting continuo del proyecto.
